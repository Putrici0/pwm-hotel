PWM Hotel es un sitio web informativo orientado a mostrar información general del hotel, sus servicios y sus diferentes espacios.

El acceso y uso de este sitio implica la aceptación de unas condiciones básicas de navegación y uso responsable del contenido mostrado.

Uso del sitio web

El usuario se compromete a utilizar la web de forma adecuada y a no emplearla para fines ilícitos, fraudulentos o que puedan perjudicar el funcionamiento del servicio.

El contenido mostrado en esta web tiene carácter informativo y puede ser actualizado o modificado cuando resulte necesario.

Protección de datos

Los datos facilitados a través de formularios de contacto serán tratados únicamente con la finalidad de gestionar consultas relacionadas con el hotel.

El usuario podrá solicitar información adicional sobre el tratamiento de sus datos a través de los canales de contacto habilitados en la propia web.
